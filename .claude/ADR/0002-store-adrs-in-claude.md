# ADR 0002: ADR の保存先を .claude/ADR に統一する

- 日付: 2026-10-26
- 状態: 採用
- 適用範囲: sandbox-notion-clone のみ

## 背景

ADR の追加・更新先を統一し、今後のエージェントによる記録も同じ場所に集約したい。
ユーザーから `.claude/ADR/` を保存先として指定された。

## 決定

すべての ADR を `.claude/ADR/` に保存する。既存の ADR 0001 もここに集約する。
独立した新しい決定は連番付きファイルを追加し、補足・訂正は既存ファイルを更新する。
方針変更は新しい ADR として記録し、旧 ADR から後継を参照して経緯を残す。
AGENTS.md に保存・更新ルールを明記し、関連するプロンプトや設定の参照先も揃える。

## 代替案

- `docs/adr/`: 一般文書とまとめられるが、今回指定された保存先とは異なるため採用しない。
- `.claude/adr/`: すでに ADR 0001 が置かれていたが、指定どおり大文字の `ADR` に統一する。

## 結果

ADR の探索先が一か所になる。既存の `.gitignore` は `.claude/` を除外しているため、
ADR はローカル記録となる。Git の追跡設定は今回変更しない。

## 2026-11-01 の公開方針変更

ADR のローカル管理・Git 非追跡に関する記述は当時の方針。現在は [ADR 0014](0014-publish-adrs-preserve-local-skills.md) により ADR を公開する。スキル本体のローカル管理は維持する。
