# ADR 0005: テンプレートとセッション照合を備えた til-review-v2 を追加する

- 日付: 2026-10-26
- 状態: 置換済み（[ADR 0006](0006-adopt-til-review-and-input-template.md)）
- 適用範囲: このリポジトリの TIL のみ
- 関連: [ADR 0004](0004-preserve-author-voice-in-til.md)（本人の言葉を保持する方針を継承）

## 背景

既存の til-review に対し、テンプレート利用と実行当日の会話を反映する方式を検討した。
分析では、混在した文章の出所判定、会話の不足、再実行時の追記の継承、
説明の重複、学習時点と現在の状態の区別、原文との照合を明確にする必要が確認された。
ユーザーは改善案の統合を依頼し、既存スキルを上書きせず別スキルにするよう指定した。

## 決定

`.codex/skills/til-review-v2/` を追加し、既存の til-review を保持する。
SKILL.md に判断手順を、assets/til-review-template.md に Markdown の骨組みを置く。
個人用スキル領域には配置しない。

- 対象パスだけの指定でも、元メモと参照可能な当日の関連する会話を確認する。
- 本人の要約、質問、教材、AI の説明、出所不明の文章を区別する。
- 会話のテーマを生成前に洗い出し、後半の追加テーマと訂正も反映する。
- 会話が不足していても利用可能な入力で進め、参照範囲と未確認事項を明示する。
- 原本・指定された復習版（指定がなければ最大版番号の候補）・新しい会話を照合し、追記を引き継ぐ。
- 説明量を固定せず、空の節や重複を省く。
- 学習時点と確認時点を区別し、今後の候補を最新の状況と照合する。
- 生成後に本人の文章との比較、関連テーマの網羅、既存ファイルの保持を確認する。

出力は既存版を上書きしない次版を既定とする。スキルの v2 と出力の版番号は別の意味を持つ。
明示的には `$til-review-v2 <対象パス>` で呼び出す。
既存の `$til-review` が指定された場合、そのスキルを優先する。

## 代替案

- 既存スキルを更新する: 比較がしづらく、今回のユーザー指定にも反する。
- 指示だけ追加する: 生成文書の構成が安定しにくいため、テンプレートを同梱する。
- 専用の生成スクリプトを導入する: 今回は文章の判断が中心であり、まず指示とテンプレートで運用する。

## 結果

既存版と比較しながら改善版を使用できる。実際の生成品質は今後の出力で確認する。
今回の作成・検証はスキルとテンプレートを対象とし、既存 TIL の再生成やコミットは行わない。
ADR 0004 は共通方針として維持する。ADR の Git 追跡設定は変更しない。
