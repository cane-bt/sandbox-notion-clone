# ADR 0006: 改善版を正式な til-review として採用し、入力用 TIL テンプレートを用意する

- 日付: 2026-10-26
- 状態: 採用
- 適用範囲: このリポジトリの TIL のみ
- 置換対象: [ADR 0005](0005-add-template-based-til-review-v2.md)
- 継承する方針: [ADR 0004](0004-preserve-author-voice-in-til.md)

## 背景

til-review-v2 の方式で復習版 v3 を作成した後、ユーザーが正式採用を依頼した。
今後は既存の til-review を改善版で上書きし、呼び出し名を統一する。
また、本人が日々書く作成メモも、本人の文章と質問、教材や AI の説明を区別しやすくしたい。

## 決定

- `.codex/skills/til-review/` に改善版の判断手順と出力用テンプレートを反映する。
  出所の区別、当日の会話の参照、既存版の追記の継承、時点の区別、原文との照合を継承する。
- 正式な呼び出し名を `$til-review <対象パス>` とする。
- 本人が書く原本用に `_TIL/TEMPLATE.md` を追加する。
  自分の要約、疑問、試した結果、教材由来の内容、AI の説明、本人が決めた次の確認事項を分ける。
- 入力テンプレートの利用は任意とし、自由形式のメモも受け付ける。
  空欄を埋めるために本人の理解や実施結果を推測しない。
- 入力用テンプレートと、スキル内の復習版出力用テンプレートは目的を分ける。
- 比較用の til-review-v2 は今回削除・変更しない。以後の標準運用は til-review を使う。
- 配置はリポジトリ内に限定し、個人全体のスキル設定には反映しない。

## 代替案

- til-review-v2 の名前を標準にする: 比較版の名前が恒久化するため、正式名へ反映する指定を優先する。
- 復習版のテンプレートを本人の入力にも使う: 本人が AI の説明欄まで埋める負担があり、用途に合わない。
- 入力形式を必須にする: 日々の自由なメモを妨げるため、推奨にとどめる。

## 結果

日々の入力から復習版作成まで、出所を区別しやすくなる。
本人は必要な欄だけ記入でき、既存の TIL を移行する必要はない。
正式名に改善版を反映するため、旧 til-review の動作は更新される。
既存の日付付き TIL とアプリのコードは変更しない。コミット・公開も行わない。
ADR の Git 追跡設定は変更しない。

## 2026-11-01 の補足
