# ADR 0007: TIL 復習版の目次をスクリプトで生成する

- 日付: 2026-10-26
- 状態: 採用

## 背景

復習版の冒頭からテーマへ移動できるようにし、毎回 AI が目次を列挙するトークン消費を減らしたい。

## 決定

til-review の scripts/update_toc.py により、本文保存後に固定 TOC マーカー内へ目次を生成する。
配置はタイトル・メタ情報の後。対象は本文のレベル2・3見出しとし、重複アンカーには全レベルを考慮する。
Python 標準ライブラリのみで、GitHub の基本的な見出しリンクを対象とする。
扱う Markdown は ATX 見出しと通常テキスト・単一バッククォートのコードに限定する。
マーカー異常では書き込まない。原本や旧版の保持、明示された上書き、提示のみの規則は維持する。

## 代替案

- AI による毎回の生成: トークン節約の目的に合いにくい。
- 固定目次: テーマの追加・省略に追従できない。
- 明示的 HTML アンカー: 本文への変更と表示環境への依存が増えるため採用しない。

## 結果

本文変更後の目次更新を機械化できる。全 Markdown 構文や全表示環境との互換性は対象外。
トークン削減量は未計測。スキルと ADR は既存の Git 除外設定に従いローカルで管理する。
