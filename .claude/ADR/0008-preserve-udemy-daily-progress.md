# ADR 0008: TIL 復習版に日付ごとの Udemy 受講進捗を残す

- 日付: 2026-11-01
- 状態: 置換済み（[ADR 0009](0009-show-cumulative-udemy-progress.md)。日別記録の保持方針は継承）
- 適用範囲: このリポジトリの til-review と TIL テンプレート
- 関連: [ADR 0006](0006-adopt-til-review-and-input-template.md)、[ADR 0004](0004-preserve-author-voice-in-til.md)

## 背景

ユーザーから、その日に Udemy の何番から何番まで受講したかを記録し、til-review で保持したいという依頼があった。
これまで番号が疑問の背景に含まれることはあったが、当日の進捗として確認する独立した欄はなかった。
コード変更と教材の対応は受講実績そのものではなく、教材一覧の完了表示も受講日を示すとは限らない。

## 決定

- 復習版の目次の後・元の学習メモの前に「Udemy の受講進捗」を置く。
- 原本・既存版・会話の明示的な受講申告から、対象日の受講日、講座の識別情報、番号範囲、状態と出所を記録する。
- 番号が飛び飛びの場合や途中まで・復習の場合は、その情報を保持する。累積の完了表示やコードから当日の実績を推測しない。
- 情報が不足していても生成を止めず、不足箇所を未確認とする。情報なしと受講なしを区別し、完了報告で不足を知らせる。
- 原本用の `_TIL/_TEMPLATE.md` に受講記録欄を追加する。自由形式の入力も引き続き受け付ける。
- 再生成でも進捗と出所を引き継ぎ、訂正や矛盾を扱う。既存の TIL はこの方針変更だけでは更新しない。

## 代替案

- 本文中の講座番号だけを残す: その日の受講範囲を確認しにくい。
- Git の差分や完了済み一覧から自動判定する: 実装日・視聴日・完了日を混同するため採用しない。
- 進捗が不明なら生成を止める: 本文の整理は進められるため、未確認として記録する。

## 結果

受講進捗と技術的な復習内容を分けて追跡できる。本人が当日の範囲を申告しない場合、正確な受講実績は確定できない。
スキルと ADR は既存のローカル管理を維持し、Git の除外設定は変えない。今回コミット・公開は行わない。
