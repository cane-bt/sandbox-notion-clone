# ADR 0009: Udemy の累積進捗と受講履歴を復習版の末尾に表示する

- 日付: 2026-11-01
- 状態: 一部置換（[ADR 0024](0024-place-original-learning-notes-last.md)。置換範囲は末尾に記載）
- 置換対象: [ADR 0008](0008-preserve-udemy-daily-progress.md)

## 背景

ユーザーは学習のモチベーション維持のため、講座の総動画数と累積進捗、日付別の受講履歴を確認したい。履歴は新しい日付順に、情報量を考慮して復習版の末尾へ置く指定がある。

## 決定

- README に講座名・URL・総動画数・確認日を記録する。
- 日々の TIL と対応する復習版の当日の受講記録を根拠に、講座ごとの完了動画を重複なしで数える。生成済みの累積値や履歴表は再集計しない。
- 復習版の末尾に当日の受講記録、累積完了数・割合・当日の成果、受講日の降順の履歴と出所を示す。
- 途中・再視聴を完了数へ追加しない。記録不足は未確認とし、未受講と断定しない。
- 対象日までに完了したと確認できる動画だけ累積に含める。時点不明の完了は別枠に保持する。
- 学習対象日・整理日・計算に使った総数と確認日を残し、後日の進捗や総数変更で保存済みの過去版を更新しない。
- ADR 0008 の出所・訂正・原本保持の方針は継承する。

## 代替案

- 上部の当日進捗のみを維持する: 累積や履歴を見たい要件を満たさない。
- 別台帳を手入力する: 入力と訂正箇所が増えるため採用しない。
- 完了時点不明の記録も過去日に算入する: 当時の進捗を過大表示するため採用しない。

## 結果

学習内容と進捗を同じ復習版から確認できる。正確な完了割合には本人の受講記録が必要であり、不足時は数値を推測しない。履歴によるファイルの情報量は増える。スキルと ADR のローカル管理、Git 除外設定は維持する。

## 保存・自動集計の補足

[ADR 0010](0010-transactional-til-review-storage.md) で原本退避と一式保存を採用。受講記録を出所付きで機械可読データへ保存して再利用する。過去版本文は保持し、原本移行に伴うリンク先変更のみ例外とする。
