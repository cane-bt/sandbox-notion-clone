# ADR 0010: TIL の原本退避・固定プレビュー・集計と再開可能な一式保存

- 日付: 2026-11-01
- 状態: 保存方式は置換済み（[ADR 0015](0015-simplify-til-storage.md)）。原文保持の方針は継承。
- 関連: [ADR 0009](0009-show-cumulative-udemy-progress.md)、[ADR 0004](0004-preserve-author-voice-in-til.md)、[ADR 0007](0007-generate-til-review-toc.md)
- 置換範囲: ADR 0004 の原本と復習版を同じフォルダに保持する配置。原文とAI説明の分離は継承。

## 背景

ユーザーは daily-review の原本退避・ハッシュ照合・安全な保存・中断復旧も採用したいと指定した。独立レビュー F1〜F6 で、会話・既存版も含む入力、リンク移行、訂正、完了条件を明確化した。

## 決定

- Python 標準ライブラリで集計と保存を分離実装し、外部リポジトリに実行時依存しない。
- AI は出所と意味を確認した実績を入力し、Python は形式検査・重複除去・全件再集計・目次・保存を担当する。成功を実績の真偽確認と混同しない。
- 原本を `_TIL/_draft/` へ全バイト保持して退避する。原本改訂時も旧版を保持する。
- 復習版は直下に版番号付きで保存し、受講データは `_data/`、処理記録は `.review-state/` に保持する。別の手入力台帳は作らない。
- 入力ハッシュと完成候補を固定し、プレビューと同じ本文を保存する。同一処理IDは再試行、新規更新は新IDと次の版で扱う。
- 原本退避・旧リンク修正・対応データ・新版・移動元除去を予定内容と照合した後だけ完了とする。未完了のデータを集計しない。
- 中断時は記録済み工程から再開する。予定の変更前後以外の内容、原本や完成物の改変、同時処理、保存先衝突は停止する。エディターはロックできないので保存中の編集は避ける。
- 既存版の移行では原本リンク先だけを修正する例外を認め、本文・当時の数値は保持する。原本内の相対リンクは変更せず影響を確認する。
- 成功後も新しい版で訂正を反映し、旧版と旧データは保持する。元データにない補足や会話由来の本人申告も出所付きで引き継ぐ。

## 代替案

- 集計のみ自動化: 原本保護・保存復旧まで取り入れる今回の要件を満たさない。
- daily-review をそのまま移植: 日記の生成済み判定・保存場所・Git除外の前提が TIL と異なる。
- DB・常駐監視・差分集計: 現在の規模には不要。全件再集計を保ち、過去文章の再解釈を減らす。

## 結果

処理記録とデータの保存量は増えるが、二重保存・中断・訂正・原本改変の扱いを検証可能にできる。複数ファイルの一括原子的更新ではなく、再開可能な順次処理であり、途中状態は記録から判断する。パフォーマンス改善量は未計測。スキルとADRのGit除外、公開とコミットの別扱いは維持する。
