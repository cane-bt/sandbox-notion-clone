# ADR 0014: ADR を Git で公開し、スキルはローカル管理を続ける

- 日付: 2026-11-01
- 状態: 一部置換（[ADR 0024](0024-place-original-learning-notes-last.md)。置換範囲は末尾に記載）
- 適用範囲: sandbox-notion-clone

## 背景

従来は .claude/ の Git 除外により ADR をローカルだけに保存していた。2026-11-01 にユーザーが、このセッションの決定を記録し PR へコミット・push・マージするよう明示した。

## 決定

- 保存先 .claude/ADR/ は維持し、既存 ADR 0001〜0010 と今回の追加 ADR を Git 追跡・公開する。
- ADR 0002 の「ローカル記録・追跡しない」という部分のみ本 ADR で置換する。他 ADR の同趣旨の記述は当時の扱いとして保持し、本 ADR へ参照を追加する。
- .claude/ 全体の除外を維持する。ADR だけを対象に git add -f .claude/ADR/<対象ファイル> で明示追加する。新規 ADR も同じ扱いとし、worktree や設定を一括追加しない。
- .codex/ の生成スキル、個人設定、エージェント設定は今回の公開に含めない。clone のみで til-review を実行できる状態にはしない。
- 既存の撤回・置換済み ADR も消さず、現在の方針と後継を追えるようにする。

## 代替案

ADR をローカルのままにする案は今回の公開依頼を満たさない。.claude/ 全体を追跡すると作業用設定を混入させる恐れがある。保存先移動は指定に反するため行わない。

## 結果

決定の経緯をリポジトリから参照できる。新規 ADR は明示的な強制追加が必要になる。スキルのソース公開は別の決定として扱う。

## 2026-11-07 の部分変更

スキルのローカル管理方針のうち、`til-review` の `SKILL.md` と出力テンプレートだけを [ADR 0024](0024-place-original-learning-notes-last.md) で公開対象へ変更。その他のスキル・個人設定・関連スクリプトのローカル管理は継続する。
