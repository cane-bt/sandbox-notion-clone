# ADR 0015: TIL の完成版を日付名に統合する

- 日付: 2026-11-01
- 状態: 採用
- 置換対象: ADR 0010 の版番号・JSON データ・保存処理記録による保存方式

## 背景

ユーザーから _TIL/.review-state/ と _TIL/_data/、11月1日の review-v3・v4 は不要であり、v5 を日付名へ変更するよう指定された。

## 決定

完成版は日付名で保存し、同日の更新は同じファイルへ反映する。版の履歴は Git で管理する。今回 v3・v4 を削除し、v5 を 2026-11-01(Sun).md へ変更する。当初は初回版・v2 と _draft の原本を保持したが、同日の追加指定によりそれらも削除する。完成版内の本人の文章は保持し、旧ファイルは Git 履歴から参照する。

受講実績・出所・進捗は Markdown に保持する。JSON 台帳と処理記録を削除し、旧 workflow.py の一式保存・再開を通常運用では使わない。今後の集計は日付名の完成版にある各日の実績と本人申告を根拠にし、過去版や累積表から重複加算しない。

## 代替案

処理記録だけ Git 除外にする案は、ファイル自体が不要という今回の指定を満たさない。従来の多版保存はファイル数と照合の負担が増える。

## 結果

閲覧対象を整理できる。保存処理記録による自動再開・ハッシュ照合は利用しなくなる。原文保持と AI 補足の分離、出所に基づく進捗記録は維持する。
