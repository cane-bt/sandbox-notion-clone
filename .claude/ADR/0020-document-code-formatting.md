# ADR 0020: ドキュメントのコード表記を共通化する

- 日付: 2026-11-02
- 状態: 採用
- 適用範囲: このリポジトリのドキュメント

## 背景

TIL のコードに関する表記をインラインコード等で装飾した結果、本人から意図に合うと確認された。今後の生成でも再現し、TIL 以外のドキュメントにも適用するため、共通ルールとスキルの役割を整理する。

## 決定

- 表記の判断基準はルートの `AGENTS.md` を正本とする。具体的な識別子・式・パス・設定等をコードとして表記し、一般的な技術名や概念は通常の文章にする。
- 本文・表・見出しに適用し、短い式は意味のまとまり全体を囲む。複数行は言語指定付きコードブロックにする。
- `til-review` は共通ルールを参照し、本人の文言保持・退避原本の非変更・生成後の照合を補足する。テンプレートには短い案内だけを置く。
- 本人の文章には文言・意味を変えない装飾を認める。これは [ADR 0004](0004-preserve-author-voice-in-til.md) の最小限の整文の補足であり、技術訂正を黙って混ぜることは認めない。
- 新規作成・依頼された更新の範囲で適用する。既存文書の一括整形、原本の変更、コード例の追加をこの決定から推論しない。
- 新しい自動置換スクリプトや独立スキルは作らず、既存の目次更新処理を使う。スキルのローカル管理は [ADR 0014](0014-publish-adrs-preserve-local-skills.md) に従う。

## 代替案

- スキルだけに規則を置く: TIL 以外にも適用したいという要望を満たさない。
- 共通ルールとスキルに同じ規則を複製する: 更新時に食い違いやすい。
- 正規表現による一括置換: 概念と識別子の文脈上の区別が難しいため採用しない。

## 結果

文書間でコード表記を揃え、文章とコードの境界を見分けやすくする。文脈の判断は引き続き必要なため、生成後は装飾漏れ・過剰な装飾と内容の保持を確認する。ルール追加だけでは既存文書を書き換えない。
