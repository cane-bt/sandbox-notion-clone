# ADR 0021: ADR の記録対象を自律的に選び追加・更新する

- 日付: 2026-11-04
- 状態: 採用
- 適用範囲: このリポジトリでの Codex による ADR の記録

## 背景

既存ルールは決定時の ADR 記録を求めているが、取捨選択の基準と記録タイミングが曖昧だった。ユーザーが記録を思い出して指示する運用への依存を減らすため、自律的な記録・更新のルール案を作成し、代替案レビュー後にユーザーが適用を指示した。

## 決定

- 判断基準の正本をルートの `AGENTS.md` に置く。選択理由を残す価値、将来の作業への制約、既存方針の変更のいずれかに該当する、将来も参照する価値がある決定を自動記録する。
- 質問への回答、一般解説、作業ログなどは原則除外する。個人設定はプロジェクトの開発方針として採用した場合に対象とする。
- 自動記録は確定した決定を対象とする。明示的な記録依頼では未採用の話題も状態を区別して保存する。採用・実装・検証を混同せず、未確認の理由や結果を補わない。
- 方針確定時に記録し、完了報告前に漏れを確認する。記録の要否だけを理由に確認待ちにしない。
- 補足・訂正は既存 ADR を更新し、方針変更は新しい ADR と後継参照で履歴を残す。部分変更では存続する決定を失効させない。
- 保存先・履歴保持は [ADR 0002](0002-store-adrs-in-claude.md)、公開方針は [ADR 0014](0014-publish-adrs-preserve-local-skills.md) を維持する。本決定はそれらを補足し、置換しない。
- 作業ブランチのルールを守り、未依頼のコミット・push・PR 作成は行わない。記録した内容は最終回答で報告する。
- まずこのリポジトリに適用する。グローバル設定への展開と既存 ADR の一括再分類・削除は含めない。

## 代替案

- 現状維持: 変更は不要だが、記録対象やタイミングの判断が曖昧なまま残る。
- 判断基準だけを追加: 変更は小さいが、採用・実装・検証の区別や明示依頼、部分置換の扱いが不足する。
- 即座にグローバルへ適用: 他のリポジトリの保存方針や適用範囲との整合性が未確認のため、今回採用しない。

## 結果

ADR の自律記録に必要な判断基準と実行タイミングを明文化する。ルールによる記録漏れ・過剰記録の低減効果は実運用では未検証であり、漏れゼロを保証しない。

今後の作業では、提案だけなら自動記録しないこと、確定した決定を記録すること、採用済み未実装の状態を保持すること、明示依頼による未採用記録と部分置換を正しく扱うことを確認する。
