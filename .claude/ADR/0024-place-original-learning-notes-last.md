# ADR 0024: TIL の元の学習メモを最終節に配置する

- 日付: 2026-11-07
- 状態: 採用
- 部分置換: [ADR 0009](0009-show-cumulative-udemy-progress.md) の最終節配置、[ADR 0014](0014-publish-adrs-preserve-local-skills.md) の限定したスキルファイルの非公開方針

## 背景

ユーザーは PR #30 の11月7日 TIL の「元の学習メモ」を指定し、今後は該当 Markdown の一番最後に記載するよう、生成指示・スキルを更新してコミット・push することを依頼した。従来はテンプレートの冒頭に元メモがあり、Udemy の学習進捗を最終節としていたため、両方の指示を整合させる必要がある。

## 決定

- このリポジトリの TIL 完成版を「学習本文・確認事項 → 参考資料 → Udemy の学習進捗 → 元の学習メモ」の順にする。
- 「元の学習メモ」は配下の補足・出所未確認の記述を含めて最終節にし、その後へ別の節や追記を置かない。内容のない節の省略は引き続き認める。
- 初回生成と再レビューの両方に適用する。今回指定された11月7日の完成版も移動して目次を更新する。対象外の過去 TIL は一括更新せず、退避済み原本の全バイト保持を継続する。
- `til-review` の `SKILL.md` と `assets/til-review-template.md` を更新する。今回の明示的な公開依頼に基づき、この2ファイルだけを Git の追跡対象へ追加する。
- その他のスキル、関連スクリプト、個人設定、エージェント設定は公開対象にしない。除外設定は変更せず、指定ファイルだけを明示追加する。公開するのは生成指示とテンプレートであり、生成環境一式の配布ではない。

## 代替案

- 今回の TIL だけを移動する: 今後の生成で元へ戻るため、スキルとテンプレートも変更する。
- 元メモの後へ進捗を置き続ける: 元メモを一番最後にする依頼と矛盾するため採用しない。
- 全スキルと補助ツールを一括公開する: 依頼された配置変更の範囲を超えるため採用しない。

## 結果

復習する説明を先に読み、末尾で原本の記述を確認できる。生成・再レビュー時の配置と確認項目を統一する。本人の文言保持、AI 補足の分離、受講実績の集計方法は変更しない。公開した指示から参照するローカル専用ファイルは clone に含まれない場合があり、README に配布範囲を明示する。
