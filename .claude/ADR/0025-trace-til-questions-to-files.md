# ADR 0025: TIL の疑問と解説を対象ファイルに対応付ける

- 日付: 2026-11-11
- 状態: 採用

## 背景

ユーザーから、過去の TIL を読んでもどのファイルについて何を疑問に思い、どのような説明を受けたか追いにくいため、今後は対象ファイルも記載してほしいという依頼があった。

## 決定

- 今後作成・更新する TIL では対象ファイルと関数名・文書の節名、疑問、対応する解説を記録する。複数ファイルの関係が対象なら双方を記載する。
- 復習版は目次の後に「疑問と解説の一覧」を置き、本文の説明へリンクする。本文にも対象箇所を明示する。
- 行番号は質問時点で確認できる補助情報として扱う。対象不明や特定ファイルのない一般論、未回答・未解決事項を区別し、質問や学習日時を推測しない。
- 本人の質問は中立的に要約し、AI の解説と本人の理解を区別する既存方針を維持する。過去の TIL と退避済み原本は今回一括変更しない。
- `AGENTS.md`、`til-review` の指示・出力テンプレート、任意の入力テンプレートを整合させる。
- 独立レビューの現状維持案を採用し、現在の構成を維持する。通常の TIL 作成時に入力に存在する質問の種類ごとに対応と出所を照合し、実際に欠落・誤対応が生じた場合に必要な箇所だけ指示や例を補強する。専用の検査スクリプトは追加しない。

## 代替案

- 解説だけをテーマ別に残す: 対象ファイルと疑問の対応が追いにくいままになる。
- 行番号だけを残す: コードの変更で対象がずれるため、パスと関数名等も記録する。
- 会話を全文転載する: 復習時の見通しを損ねるため、疑問と解説を対応付けた要約を採用する。

## 結果

ファイルや疑問を起点に解説を探せる形式を今後の生成手順に組み込む。指示とテンプレートへの反映後、11月11日の TIL に新形式を適用した。原本のバイト一致、目次、対象ファイルと本文へのローカルリンク58件、疑問と説明の対応を確認した。

独立レビュー2回で文書の整合性を確認し、修正必須事項は指摘されなかった。初回生成で通常のファイル質問、複数ファイルの関係、TIL 内の説明用コードへの質問を対応付けた。今回入力にない対象不明・未回答のケースは生成検証していない。公開を依頼された際は、この ADR が Git の除外対象であることを踏まえ、一覧のリンク先も公開コミットに含まれるか確認する。
