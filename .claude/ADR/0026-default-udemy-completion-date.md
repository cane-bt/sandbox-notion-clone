# ADR 0026: TIL の完了記録は対象日を既定の受講日とする

- 日付: 2026-11-12
- 状態: 採用
- 関連: [ADR 0009](0009-show-cumulative-udemy-progress.md) の日別記録・集計方針を補足

## 背景

日付付き TIL の「Udemy の受講進捗」に動画番号と「完了」が記載されていても、受講日欄が空欄という理由で完了日を再質問していた。ユーザーはこの記載を当日の実績として伝えており、毎回の確認を不要とした。入力テンプレートもその日に受講した範囲を記す設計だが、日付省略時の扱いが明文化されていなかった。

## 決定

- 本人が受講進捗欄に記載した完了記録は、別の受講日や累積記録という明示がなければ、TIL の対象日の完了申告として扱う。整理日を代用しない。
- 受講日欄の空欄や教材表示の貼り付け形式だけでは再質問しない。明示された受講日を優先し、解消できない矛盾だけを確認する。
- 情報不足時は不足箇所を未確認として生成を続ける。受講記録自体がない場合と日付欄だけの空欄を区別する。
- `til-review` と入力テンプレートに反映する。累積表示を当日の実績にしない制約、重複除外、出所保持は継続する。出力テンプレートと過去の TIL・退避原本は変更しない。

## 代替案

- 現状維持：日付省略時の解釈が曖昧なままで、確認が繰り返され得る。
- すべての完了表示を対象日の実績とする：明示された別日や累積表示を誤って扱うため採用しない。
- 毎回受講日を必須入力にする：日付付き TIL と重複する記入・確認を増やすため採用しない。

## 結果

日付付きの記録を本人の申告として受け取り、不要な確認を減らす。受講日空欄、教材表示の貼り付け、別日明記、累積表示、矛盾、進捗未記入の各ケースを文書上で照合する。実際の生成での運用効果は未検証。
