# ADR 0028: 学習用途の lint の指摘を許容する

- 日付: 2026-11-20
- 状態: 採用
- 適用範囲: sandbox-notion-clone のみ
- 関連: [ADR 0027](0027-merge-open-prs.md) の lint 許容条件を置換。その他のマージ条件は維持。

## 背景

PR #44 の全体 lint に既存の9 errors・4 warningsが残り、マージ時の許容方針を確認した。ユーザーは「このリポジトリでは、lintのエラー、warningはすべて許容」「このリポジトリ限定」「学習用のため」と明示した。

## 決定

- lint の error・warning は既存・新規を問わず許容し、指摘だけをコミット・公開・マージの阻害要因にしない。他のリポジトリへ適用しない。
- lint は引き続き実行し、失敗や指摘数を正確に報告する。検査を無効化せず、指摘を消すためだけの修正を自動で追加しない。
- build・実際の不具合・GitHub の必須チェックやレビューは別に評価する。lint の許容を保護ルールの管理者迂回の許可にはしない。
- `AGENTS.md`、README、公開・マージスキルの該当規定を整合させる。lint 設定や依存関係は変更しない。

## 代替案

- 既存の lint 指摘だけを許容する: 今回の明示方針より狭いため採用しない。
- すべて修正してから公開する: 学習用として許容するという意図に合わない。
- lint を実行しない: 学習時のフィードバックと検証結果が失われるため採用しない。

## 結果

PR #44 は本方針の明示後にマージした。build・変更箇所の lint・モック UI 検証の成功は先の検証記録で確認し、先行 PR の変更が文書・スキルのみであることと対象 head が不変であることを照合して再利用した。GitHub の必須チェック・保護ルールは当該実行時点では設定されていなかった。

この追加方針の文書はマージ後に別ブランチへ記録した。文書作成を、その追加文書のコミット・公開の許可と同一視しない。
