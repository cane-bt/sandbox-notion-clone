# ADR 0029: PR マージ後にローカル `main` を同期する

- 日付: 2026-11-22
- 状態: 一部更新。同期手順は維持し、同期後のチェックアウトを [ADR 0032](0032-finish-merge-on-main.md) で変更。

## 背景

11月20日の TIL は GitHub にマージ済みだったが、ローカルの `main` が古く、切り替え後にファイルが見えなかった。

## 決定

順次マージの終了時に、取り込みを確認した PR があればローカルの `main` も fast-forward し、取得した先端との一致を確認する。作業中のブランチと変更を保護し、同期できない場合は理由を報告する。

## 代替案

従来どおり取得だけ行い、手動で同期する方法では、ローカルの更新忘れが再発する。

## 結果

安全に同期できれば次に `main` を開いたときにマージ済みの内容が見える。履歴が分岐した場合などは同期を保留する。
