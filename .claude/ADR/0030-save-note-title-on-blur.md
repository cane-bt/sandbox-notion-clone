# ノートタイトルはフォーカスが外れたときに保存する

2026-11-22　採用・実装済み

## 背景

タイトルを入力するたびに送信すると、複数の更新が並行し、古い応答がストアのタイトルを上書きする可能性がある。

## 決定

入力中の値を画面の下書きとして保持する。フォーカスが外れ、保存済みのタイトルと異なる場合に送信する。この画面では保存中の入力を無効にし、成功時にストアを更新する。失敗時は下書きを保持して再試行を受け付ける。

## 代替案

入力中の自動保存には、送信頻度と更新順序の制御が必要になる。今回は入力を終えたタイミングで保存する方法を選んだ。

## 結果

1回の編集で入力文字ごとの通信を避けられる。応答待ちの間は追加入力できない。モック API で保存・失敗・再試行を確認した。実バックエンドでの動作は未確認。
