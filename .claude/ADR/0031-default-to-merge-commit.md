# ADR 0031: PR の既定マージ方式を Merge commit にする

- 日付: 2026-11-22
- 状態: 採用

## 背景

PR #48 では Merge commit と Rebase merge の両方が許可され、方式の選択で作業が一時停止した。

## 決定

このリポジトリの PR は、個別の明示指定がない限り Merge commit で取り込む。通常のマージでは `gh pr merge --merge` を使い、確認済みの head SHA を指定する。必須の merge queue があればその規則を優先する。既定方式が禁止されている場合は保留する。

## 代替案

Rebase merge ではコミットの SHA が変わる。毎回選択する運用では同じ確認を繰り返すことになる。

## 結果

公開した個々のコミットを元の SHA で追跡でき、取り込みの境界も履歴に残る。GitHub の許可方式の設定は変更しない。
