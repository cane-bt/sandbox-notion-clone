# ADR 0032: マージ後は元ディレクトリで最新の `main` に戻る

- 日付: 2026-11-22
- 状態: 採用

## 背景

PR #48 の取り込み後、ローカルの `main` は更新されたが、元ディレクトリは作業ブランチを表示していた。

## 決定

1件以上のマージを確認したら、[ADR 0029](0029-sync-local-main.md) の同期後、元ディレクトリで安全に `main` へ切り替え、ブランチ名と取得済み SHA を確認する。作業中の変更や別 worktree による使用などで切り替えられない場合は、同期と切り替えの結果を個別に報告する。

## 代替案

参照だけを更新する従来の手順では、次の作業前に手動でチェックアウトする必要がある。

## 結果

通常はマージ済みのファイルを元ディレクトリですぐ参照できる。元の作業ブランチは引き続き利用できる。
