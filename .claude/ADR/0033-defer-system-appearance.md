# OS の外観設定への追従は教材に沿った実装後に行う

2026-11-23　延期を決定・外観設定への追従は未実装

## 背景

ノートページの背景色は白に固定されている。一方、教材と同じように `BlockNoteView` の `theme` を省略すると、BlockNote はシステムの外観設定に従う。そのためダークモードでは、白いページの中でエディターだけが暗く表示される。

## 決定

今回は教材に沿ってエディターの学習を進めるため、ページを OS の外観設定に追従させる対応を見送る。ライトモードとダークモードのどちらでもページとエディターの配色が揃うことを、今後の対応事項として残す。

## 代替案

ページ側で `prefers-color-scheme` を使い、背景色や文字色を切り替える方法がある。また、エディターに `theme="light"` を指定すると現在の白いページには揃うが、ダークモードを選んだユーザーにもライト配色が適用される。

## 結果

現段階では配色の差を許容する。将来対応する際は、ライト・ダークの両方でページとエディターの背景が揃い、タイトル、本文、サイドバーの文字が読み取れることを確認する。
