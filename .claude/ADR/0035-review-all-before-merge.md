# ADR 0035 全対象のコードレビューを順次マージの開始条件にする

- 日付　2026-11-24
- 状態　一部置換。全件の事前レビューと SHA の照合は継続。不具合発見時の一律停止は [ADR 0036](0036-record-merge-review-findings.md) で置換。

## 背景

本文保存の実装に不具合が見つかった際、独立した学習記録だけが先にマージされた。利用者は一連の変更を取り込む前に改善点を確認したい。

## 決定

固定した全対象の差分と検証記録を最初のマージ・予約前に確認する。コード上の不具合を確認したら全件を保留し、改善点と検証方法を示す。開始後に判明した場合は全残件を停止する。[ADR 0027](0027-merge-open-prs.md) の独立 PR 続行方針をコード上の不具合について置き換える。

## 代替案

各 PR の直前にだけ確認する方式では、後続 PR の問題を知る前に先行 PR のマージが完了し得る。

## 結果

最初のマージまでに全件分のレビューを行う。同じ SHA と条件に対応する検証結果は再利用できる。開始前の SHA 照合に加え、順次実行中も依存先の完了と最新状態を確認する。
