# ADR 0036 レビューの問題を ADR に記録して PR ごとに判断する

- 日付　2026-11-25
- 状態　採用

## 背景

独立した TIL も含めて PR #56・#57 が保留されたことを受け、この学習リポジトリに限り全件保留ルールを外すよう依頼された。

## 決定

レビューで見つけた問題は ADR に記録し、各 PR は依存関係・検証・GitHub の必須条件に従って個別に判断する。 問題の発見だけでは当該 PR も残件も一律に止めない。開始前・開始後ともに適用する。

## 代替案

ADR 0035 の一律停止では、問題と無関係な作業も待つ。口頭報告だけでは対応判断を後から追いにくい。

## 結果

全対象の事前レビューを継続する。問題ごとに PR・箇所・根拠・未確認事項・改善案・確認方法を残し、既存の記録があれば更新する。競合や必須チェック失敗は従来どおり個別に扱う。
