# ADR 0037 検索モーダルのフォーカス管理を確認事項として残す

- 日付　2026-11-25
- 状態　課題を記録・修正方針は保留

## 背景

[PR #56](https://github.com/cane-bt/sandbox-notion-clone/pull/56) の head `3048f3b` をレビューした。検索モーダルは開いた直後のフォーカスを設定する。

## 決定

キーボード操作の問題を記録し、修正方法の選定は保留する。対象は [DialogContent](../../src/components/ui/dialog.tsx) と [SearchModal](../../src/components/SearchModal.tsx)。

## 代替案

フォーカスを循環させ、閉じたときに検索ボタンへ戻す実装を加える方法と、フォーカス管理を備えたダイアログ部品を使う方法がある。

## 結果

コード上、ダイアログ内の先頭・末尾でフォーカスを循環させる処理と、閉じた後に起点へ戻す処理を確認できなかった。背景にフォーカスが移る可能性がある。実機での再現と修正は未確認。検索ボタンから開き、先頭で Shift+Tab、末尾で Tab を押して移動先を確認し、Esc で閉じて検索ボタンに戻るか確認する。
