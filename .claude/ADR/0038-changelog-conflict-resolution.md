# ADR 0038 英日変更履歴の独立した追記競合をマージ手順で解消する

- 日付　2026-11-25
- 状態　採用

## 背景

#56 の検索モーダル追加と当時の `main` の運用変更は、同日の英日変更履歴で競合した。双方を掲載できる内容でも、従来の手順では #56 とその実装を説明する #57 が保留になった。

## 決定

[ADR 0027](0027-merge-open-prs.md) の競合保留・修正権限を部分変更する。通常の明示依頼では、英日変更履歴の独立した追記だけが競合した場合、検証済みの統合コミットを同一リポジトリの非保護 PR head に通常 push できる。対象判定と予約・同時更新時の扱いは [スキル](../../.codex/skills/merge-open-prs/SKILL.md) に集約する。

## 代替案

個別の修正依頼は権限を狭く保てるが、独立した追記でも処理が中断する。一般的な競合解消まで許す案は、コードや既存項目の意味を選び直す判断まで含むため見送った。

## 結果

双方の記録を保存し、実際に送るコミットを検証してからマージ判断に戻れる。通常 push の直前照合と更新の間には競合の余地があり、厳密な旧 SHA 一致が必要な場合は保留する。
