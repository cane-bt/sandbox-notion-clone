# sandbox-notion-clone

A React + TypeScript + Vite sandbox for a Notion-style application. The current app displays `hello world`; editor and persistence features are not implemented yet.

## Development

Requires Node.js 20.19+ on the 20.x line, or Node.js 22.12+ (as required by Vite), and npm.

```sh
npm ci
npm run dev
```

## Validation and build

```sh
npm run lint
npm run build
npm run preview
```

The production build is written to `dist/`. `preview` serves that build locally.
