## 確認したこと・理解の整理

### 引数とリクエスト先の対応

**対象ファイル・箇所**

[src/modules/notes/note.repository.ts](../src/modules/notes/note.repository.ts) の `noteRepository.find`。質問時点の7行目が `params` の指定箇所。

**確認の出発点**

本人の質問：`params` に値がある場合とない場合の違いを知りたい。

**AI による補足**

2026-11-12 の確認時点では、次のコードで取得条件を設定している。

```ts
async find(options?: { parentId: number }): Promise<Note[]> {
  const result = await api.get('/notes', {
    params: { parentId: options?.parentId },
  });
  return result.data.notes.map((data: Note) => new Note(data));
}
```

`options?` は引数を省略できるという TypeScript の型指定。`options?.parentId` は JavaScript の optional chaining で、`options` が `undefined` または `null` なら、プロパティ参照でエラーにせず `undefined` を返す。ここでの引数の型は `null` を指定するためのものではない。

Axios の `params` は URL のクエリパラメータを指定する設定。リクエストのボディとは別に扱う。[Axios の公式資料](https://axios-http.com/docs/req_config) で設定の役割を確認した。

| 呼び出し方（説明用の例） | 式の評価結果 | リクエスト先のパスとクエリ |
| --- | --- | --- |
| `noteRepository.find({ parentId: 123 })` | `123` | `/notes?parentId=123` |
| `noteRepository.find()` | `undefined` | `/notes` |

実際には [src/lib/api/index.ts](../src/lib/api/index.ts) の `baseURL` を基準に送信先が決まる。表ではその部分を省略している。

`parentId=123` は親 ID を取得条件として伝える意図の指定。ただし、どのノートを返すかはサーバー側の処理で決まる。パラメータ省略時に全件を返すか、親のないノートだけ返すかは、今回確認できていない。

### `undefined` と空文字の違い

**対象ファイル・箇所**

[src/modules/notes/note.repository.ts](../src/modules/notes/note.repository.ts) の `noteRepository.find` 内にある `options?.parentId` と `params`。

**確認の出発点**

本人は追加で「なんでundefinedの時はパラメーターが空になり、`/notes`に値を送るという認識で良いでしょうか。ちょっとそこら辺が微妙な感じがします。」と質問した。これは確認中の疑問として残し、理解済みとは扱わない。

**AI による補足**

処理は2段階に分かれる。

1. JavaScript が `options?.parentId` を評価する。引数を省略した場合は `undefined` になり、Axios に渡す設定は `params: { parentId: undefined }` になる。この時点で `params` が空のオブジェクトになるわけではない。
2. Axios が設定を URL に変換する。通常のシリアライズでは値が `undefined` の項目を URL に含めないため、`parentId` というパラメータ自体が送られず、`/notes` への GET リクエストになる。

| Axios に渡す設定（説明用の例） | URL | 意味 |
| --- | --- | --- |
| `params: { parentId: 123 }` | `/notes?parentId=123` | 値を指定する |
| `params: { parentId: '' }` | `/notes?parentId=` | 空文字を指定する |
| `params: { parentId: undefined }` | `/notes` | パラメータ自体を省略する |

空文字の行は Axios の挙動を比較する例であり、`find` の `parentId: number` に空文字を渡せるという意味ではない。

「空の値を送る」と「パラメータを送らない」は異なる。optional chaining 自体に URL を変更する機能があるわけでもない。

整理時に、このリポジトリへインストール済みの Axios の `getUri` で表の3通りを確認し、表どおりの URL が生成された。これは通信を行わない URL 生成の確認であり、実際のサーバー応答を検証したものではない。
